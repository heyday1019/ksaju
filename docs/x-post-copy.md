## ⚠️ 쓰면 안 되는 표현

- **"I drew / I illustrated / hand-drawn"** — 타로 아트는 AI 생성물을 아트디렉션해서 만든 것입니다
  (`docs/tarot-imagen-consistency-guide.md`). 직접 그렸다고 쓰면 나중에 드러났을 때
  계정 신뢰가 통째로 무너집니다. 아래 문구는 전부 **"designed" / "made in one style"** 로 썼습니다 —
  사실이면서 충분히 매력적입니다.
- **아이돌 실명·사진** — 앱에서 궁합 식별용 공개정보로 쓰는 것과, 그걸로 상품을 홍보하는 건 다릅니다.
- **"accurate reading" / "real fortune telling"** — 포지셔닝이 무너지고 소비자 이슈도 생깁니다.

## 📌 게시 전략 (문구보다 이게 중요합니다)

1. **첫 트윗 본문에 Ko-fi 링크를 넣지 마세요.** X 는 외부 링크가 있는 게시물의 도달을 낮춥니다.
   **아트 이미지 + 문구로 먼저 올리고, 링크는 셀프 리플라이에 답니다.** 이게 실제로 차이가 큽니다.
2. **아트를 앞세우세요.** 지금 KSaju 에서 가장 공유될 만한 자산은 앱 기능이 아니라 **타로 카드 그림**입니다.
   "무료 사주 사이트" 는 스크롤에서 멈추지 않지만, 한복 입은 타로 카드는 멈춥니다.
3. **해시태그는 3개 이하.** 실제로 활발한 곳만: `#tarot` `#tarotcommunity` `#koreanart`
   (덱·아트 계열은 이 태그들이 살아 있습니다. `#kpop` 은 궁합 기능 얘기할 때만.)
4. **팔로워가 적을 때 도달을 만드는 건 태그가 아니라 리플라이입니다.** 같은 태그의 타로 계정 게시물에
   성실하게 답글을 다는 게, 내 게시물을 10개 더 올리는 것보다 빠릅니다.

## 11) K-pop 아이돌 궁합 기능

**이미지:** `x-04-compat.png` (실제 `/inyeon` 화면. 가짜 UI 목업이 아니라 진짜 스크린샷입니다.)

**정확한 숫자: 149명 / 29그룹** — DB 를 직접 세었습니다. CLAUDE.md 의 124/24 는 낡았습니다.

### ⚠️ 이 기능 홍보에서만 조심할 것

- **아이돌 사진·로고 절대 금지.** 이름·생일은 공개정보라 쓸 수 있지만(앱이 이미 그렇게 씁니다),
  공식 이미지는 다른 문제입니다. `x-04` 는 이름 이니셜 원형만 나와서 안전합니다.
- **이름 사용 범위 정정:** 앞 ⚠️ 섹션의 "카피에 아이돌 이름 쓰지 말 것" 은
  **Ko-fi 유료 상품 홍보**에 한정된 얘기입니다. 무료 기능을 소개하며 그룹명을 부르는 건
  팬 앱에서 일상적이고 위험도가 훨씬 낮습니다. **파는 것에 이름을 붙이지 않는다** 가 기준선입니다.
- **공식 계정에 @ 멘션 금지.** 스팸으로 읽히고 팬덤에게 역풍을 맞습니다.
- **"진짜 연애 궁합" 로 팔지 말 것.** 팬덤 shipping 의 가벼운 재미 선을 지킵니다.
- **스크린샷에 본인 사주가 찍혀 있습니다** (`己未 · 甲戌 · 己未`). 사주 4기둥은 역산하면
  생년월일이 나옵니다. 본인 생일이 공개돼도 괜찮은지 한 번 생각해보세요.
  꺼려지면 아무 날짜나 넣고 다시 캡처해서 `scripts/assets/screenshots/inyeon.png` 를 교체한 뒤
  `npm run gen:products` 를 다시 돌리면 됩니다.
